# Frontend

Next.js App Router application in `apps/web`.

## Surfaces

- Public marketing + verify + demo
- Developer dashboard
- API playground
- Documentation pages

## Patterns

- TanStack Query for server state
- Centralized `services/api.ts` client (no ad-hoc fetch in random components)
- Reusable UI in `components/ui`
- Feature modules for verify/demo/playground

## Brand

Trust-oriented payment infrastructure aesthetic with ICE branding as a first-viewport signal.
